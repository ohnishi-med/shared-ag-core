# ドキュメント視覚確認スキル (doc-visual-reviewer)

このスキルは、Word文書（`.docx`）から各ページのPNG画像を生成し、視覚的なレビューを行うための手順と自動スクリプトを提供します。
COMコンポーネント（MS Word）の制約をバイパスし、日本語のファイル名であっても安全に高解像度画像に変換します。

## 前提条件

このスキルを使用するには、以下の環境が整っている必要があります。
- **OS**: Windows (Wordがインストールされ、DCOMサービスが有効であること)
- **Pythonライブラリ**:
  - `pywin32` (COM連携用)
  - `PyMuPDF` (PDFからPNGへの高精度レンダリング用)

## スクリプトの配置と使用方法

変換スクリプトは以下に配置されています：
`scripts/docx_to_png.py`

### 実行コマンド

コマンドラインから以下を実行して、指定したDOCXファイルの全ページをPNGに変換します。

```bash
python .agent/skills/doc-visual-reviewer/scripts/docx_to_png.py "[DOCXファイルの絶対パス]" "[出力先フォルダの絶対パス(省略時はDOCXと同フォルダ)]"
```

## デザイン確認フロー（QAプロセス）

1. **スクリプトの実行**: 上記コマンドを実行して画像を生成します。
2. **画像の確認**: `view_file` などのファイルビューア機能を使用し、生成された `[ファイル名]_page[N].png` を読み込みます。
3. **目視検証の基準**:
   - **全体のページ数**: ドキュメントが想定されたページ数（例: 4ページ）にきれいに収まっているか。次のページへのわずかなはみ出し（1〜2行のはみ出しによる白紙ページ生成）がないか。
   - **フォントとスタイリング**: フォントサイズ、ボールド、カラー設定が統一されており、崩れがないか。
   - **余白と間隔**: 段落の間隔や、表セルのマージンが詰まりすぎて読みにくくなっていないか、または広すぎて領域を無駄にしていないか。
   - **罫線と入力欄**: チェックボックス（`□`）や、手書き用下線などのフォーム要素が正常に描画されているか。
