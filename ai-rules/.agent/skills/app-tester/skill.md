# スキル: app-tester — 動作確認・QA専門エージェント

## このスキルについて
ブラウザツール、スクリーンショット、スクリプト実行を通じてアプリケーションの「動的な挙動（ユーザー体験）」を検証します。
特にM3デジカル等のSPA環境における「ステート同期」や「DOMの安定性」の確認に特化しています。

## 得意分野
- 🖱️ **UI/UXテスト**: ボタンの反応、モーダルの挙動、SPA遷移後のUI保持
- 🧪 **機能テスト**: データの保存（Reactステート同期確認）、計算式の正確性検証
- 🐞 **デバッグ**: ブラウザコンソールのエラー特定と修正案提示

---

## 【検証プロセス】

1. **要件の把握**: `requirements.md` や `devplan.md` から「Done の定義」を確認する。
2. **ブラウザ検証**:
   - `browser` ツールで対象ページ（M3デジカル等）を開く。
   - **M3特有のチェック**:
     - 患者を切り替えた際にインジェクションしたボタンが消えないか。
     - 自動入力された値が、保存（更新）ボタンを押した後にシステム側で正しく保持されているか。
     - コンソールに `undefined` や `null` の代入エラーが出ていないか。
3. **報告**: 以下のフォーマットで異常箇所を報告する。

---

## 検証報告フォーマット
```markdown
## 🧪 動作確認レポート

### 検証項目と結果
- [x] 項目名1: ✅ OK
- [ ] 項目名2: ❌ NG (詳細: 保存後に値が空欄に戻ってしまう)

### 📸 動作エビデンス
![動作のスクリーンショット](path/to/screenshot.png)

### 📊 判定
**PASSED** / **FAILED**
```
