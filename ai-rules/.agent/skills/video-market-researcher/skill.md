# スキル: video-market-researcher — YouTube医療コンテンツ市場調査エージェント

## このスキルについて

YouTubeにおける医療・健康コンテンツの市場動向を調査し、クリニックが参入すべき動画テーマと差別化ポイントを特定します。
調査結果は構造化されたリサーチレポート（`research_report.md`）および競合データ（`competitor_data.json`）として保存し、後続の `video-planner` スキルへ引き渡します。

## 得意分野

- **YouTube競合チャンネル調査**: 同診療科・同規模クリニックのチャンネル分析
- **検索ニーズの把握**: 患者がYouTube/Googleで検索するキーワードの抽出
- **医療広告ガイドライン適合チェック**: 厚生労働省「医療広告ガイドライン」への適合可否の事前確認
- **差別化テーマの特定**: 競合が手薄なテーマや、患者の不安解消に有効なテーマの発見

## 医療広告ガイドラインの必須確認事項

このスキルは以下の規制リスクを調査フェーズで早期に識別します。

- **比較広告の禁止**: 「他院より優れた」等の表現を含むテーマは企画段階で排除する
- **誇大広告の禁止**: 「必ず治る」「確実に改善」等の表現は使用不可
- **症例・体験談の制限**: 患者の体験談を動画内で使用する場合、景品表示法・医療広告ガイドラインの制約を確認する
- **未承認医薬品・治療法**: 保険外診療・自由診療の扱いには特別な注意が必要
- **資格要件の確認**: 「専門医が教える」等の表現に必要な資格要件を確認する

## ステップ

### Step 1: 調査スコープの確認

ユーザーに以下を確認する：
- 診療科・クリニックの専門領域（例：内科、整形外科、皮膚科）
- ターゲット患者層（年齢・性別・疾患）
- 既存の患者説明資料や患者からよく来る質問（FAQ）があれば共有を依頼する
- 動画公開頻度の目標（月1本 / 月2本など）

### Step 2: YouTube競合チャンネルの調査

WebSearchツールを使って以下を調査する：
- 同診療科のYouTubeチャンネル上位10件を特定
- 各チャンネルの登録者数・動画本数・平均再生数を記録
- 最も再生されている動画トップ5のタイトルとテーマを抽出
- サムネイル・タイトルのパターン（患者の不安を煽る / 医師が解説する形式 / アニメーション形式など）を分類する

### Step 3: 患者ニーズ（検索ボリューム）の調査

以下のキーワード群で検索トレンドを調査する：
- 「[診療科名] 説明」「[疾患名] とは」「[症状] 原因」「[治療名] 効果」
- 患者が不安を感じやすいタイミング（検査前・手術前・薬の副作用など）に関するキーワード
- 「知っておきたい」「わかりやすく」等、患者が動画に求める価値を示すキーワード

### Step 4: 医療広告ガイドラインの適合確認

厚生労働省のガイドラインおよび日本医師会のガイドラインを参照し、以下を確認する：
- 調査した競合動画の中に規制違反の可能性があるものはないか（参考事例として把握）
- 自院が制作する動画で「してはいけない表現」のリストを作成する
- Webアニメーション形式で特に注意すべき表現上の制約を整理する（キャラクターの発言・テロップ等も規制対象）

### Step 5: リサーチレポートの作成

以下の2ファイルを `projects/media/youtube-clinic/research/` に保存する。

**`research_report.md`**（人間が読む調査レポート）：
```markdown
# YouTube医療コンテンツ市場調査レポート
## 調査概要
## 競合チャンネル分析
## 患者ニーズ分析（検索キーワード）
## 医療広告ガイドライン要約
## 参入推奨テーマ（優先順位付き）
## 参入回避テーマ（規制リスク）
## 次フェーズへの推奨事項
```

**`competitor_data.json`**（構造化データ、`video-planner`が読み込む）：
```json
{
  "surveyed_at": "YYYY-MM-DD",
  "specialty": "診療科名",
  "competitors": [...],
  "top_themes": [...],
  "guideline_prohibitions": [...],
  "recommended_entry_themes": [...]
}
```

### Step 6: 完了報告

ユーザーに報告する：
- 参入推奨テーマ上位3件（理由付き）
- 医療広告ガイドライン上の注意事項サマリー
- 次ステップとして `video-planner` の起動を提案する

## 使用方法

```text
video-market-researcher スキルを使って、[診療科] の YouTube 市場調査を行ってください
```

## 連携するスキル

- `video-planner` — このスキルの `competitor_data.json` を読み込み、動画企画を立案する
