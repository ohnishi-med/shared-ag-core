# スキル: video-planner — 動画企画・構成設計エージェント

## このスキルについて

`video-market-researcher` が収集した市場データをインプットとして受け取り、クリニックの患者説明用Webアニメーション動画の企画・構成を設計します。
医療広告ガイドラインに適合した範囲で、患者の「知りたい・不安を解消したい」というニーズに応えるコンテンツ構造を設計するのが主な役割です。

## 得意分野

- **動画テーマ選定と優先度付け**: 市場調査データに基づくテーマの優先順位化
- **コンテンツ構成の設計**: 動画の章立て・流れ・尺のバランス設計
- **Webアニメーション向け演出コンセプト**: Remotionで実現可能なアニメーション表現の企画
- **シリーズ構成の設計**: 複数動画のシリーズ化・相互参照の設計

## Webアニメーション形式の設計原則

このスキルが設計する動画はすべて **医師が映らないWebアニメーション形式** です。
以下の制作特性を考慮して企画を設計します。

- **Remotion（React/TypeScript）で制作**: テキスト・図解・キャラクターアニメーションが主体
- **ナレーション中心**: 医師の顔出しなし、ナレーション音声＋テロップで情報を伝える
- **医療図解の活用**: 体の断面図・フローチャート・比較表のアニメーション化
- **尺の目安**: 3〜7分（患者の集中力とYouTubeの推奨尺を考慮）
- **患者プライバシー保護**: 実患者の映像・写真・個人特定可能な情報は一切使用しない

## ステップ

### Step 1: リサーチデータの確認

`projects/media/youtube-clinic/research/competitor_data.json` を読み込み、推奨テーマを確認する。
ファイルが存在しない場合は、`video-market-researcher` スキルの実行を先にユーザーへ促す。

### Step 2: 動画テーマの決定

ユーザーと協議して以下を決定する：
- 今回企画する動画テーマ（単発 or シリーズ第1回）
- ターゲット視聴者の具体的な状況（例：「初めて糖尿病と診断された患者」）
- 動画を見た後に視聴者が取るべきアクション（例：「次回受診時に医師に血糖管理の目標を聞く」）

### Step 3: 動画構成の設計

以下の標準構成テンプレートをベースに、テーマに合わせた章立てを設計する：

```
[標準構成テンプレート]
0:00〜0:30  オープニング（クリニック名・タイトル・「今日わかること」の提示）
0:30〜N:00  本編（章立て）
  - Chapter 1: 疾患・症状の概要（図解アニメーション）
  - Chapter 2: なぜこの治療が必要か（根拠の説明）
  - Chapter 3: 治療・検査の具体的な流れ（フローチャートアニメーション）
  - Chapter 4: よくある不安・Q&A（テキストアニメーション）
N:00〜末尾  クロージング（まとめ・次回予告・クリニック情報）
```

テーマに応じて章を追加・削除・並び替えする。各章の秒数目安を明記する。

### Step 4: アニメーション演出コンセプトの設計

各章で使用するRemotionコンポーネントの種類を列挙する（詳細なコード化は `video-script-writer` が担当）：
- テキストフェードイン
- 医療図解（SVGアニメーション）
- 比較表（2カラムのスライドイン）
- フローチャート（ノードが順番に出現）
- 人体シルエット等の単純なキャラクターアニメーション
- プログレスバー（治療ステップの進行表示）

### Step 5: 医療広告ガイドライン適合チェック

設計した構成について以下を確認する：
- タイトル・サムネイルに誇大表現が含まれないか
- 「治る」「絶対」「No.1」等の禁止表現が含まれないか
- 自由診療の動画の場合、料金・効果の明示方法が適切か
- 視聴後に患者が誤解するリスクのある表現を排除したか

問題があれば構成を修正する。

### Step 6: 企画書の作成

`projects/media/youtube-clinic/plans/` に企画書を保存する。

**`video_plan_{テーマ名またはNo}.md`**：
```markdown
# 動画企画書: {タイトル}

## 動画概要
- テーマ:
- ターゲット視聴者:
- 目標アクション（視聴後に患者が取るべき行動）:
- 想定尺:
- 形式: Webアニメーション（Remotion）

## 構成（タイムライン）
| 時間 | 章 | 内容概要 | 演出コンセプト |
|------|-----|---------|--------------|

## 医療広告ガイドライン確認
- [ ] 比較広告なし
- [ ] 誇大表現なし
- [ ] 患者プライバシー保護確認済み
- [ ] 自由診療の場合の料金表示確認済み

## 制作備考
（スクリプトライターへの引き継ぎ事項）
```

### Step 7: 完了報告

- 企画書のサマリーをユーザーに提示する
- `video-script-writer` スキルへの引き継ぎを提案する

## 使用方法

```text
video-planner スキルを使って、「[テーマ]」の動画企画書を作成してください
```

## 連携するスキル

- `video-market-researcher` — 市場調査データをインプットとして受け取る（先に実行が必要）
- `video-script-writer` — この企画書をインプットとして、スクリプトとRemotionアニメーション仕様を作成する
