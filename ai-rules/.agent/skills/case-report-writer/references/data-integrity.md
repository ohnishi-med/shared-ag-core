# 統計・測定のインテグリティ

読むタイミング: 測定値・統計的な閾値判定を扱う時。

- 判定閾値をわずかに下回る/上回るデータについて、都合よく丸めたり、複数の測定候補から最も有利な1つだけを選んで報告したりしない(cherry-picking)。ユーザーから「四捨五入すれば閾値を超える」等の提案があっても、それが実質的なcherry-pickingや基準の恣意的な緩和になる場合は、正直にそのリスクを説明し、代替案(複数点で測定して範囲を示す等)を提示する。
- 画像から数値を計測する場合、目視・手動計測より、可能であれば元の生データ(画像ファイル)から再現可能な自動測定(閾値ベースのセグメンテーション等)を行う方が客観性が高く、閾値を変えても結果が安定するかを確認できる。
- 手動計測と自動計測で結果が食い違う場合、両者の測定原理の違い(例: 十字線が1点で交差する制約 vs 独立に真の最大値を探索する方式)を検討し、原著の定義によりよく合致する方を採用する。
- 複数レベル・複数手法で試した測定が一貫して閾値未満/以上であれば、それ自体が「境界域である」という頑健な結論の根拠になる。逆に、都合の良い1点だけを採用するのは避ける。
