# 予告文・権威依存の表現、Scientific writingとしての文章洗練

読むタイミング: 大幅改稿の完了後・投稿直前。

## 予告文・権威依存の表現を避ける

- Backgroundの結び等で「本報告では…について考察する("We discuss the pathophysiological reasoning, ...")」のような、**後続セクションの内容を予告するだけの一文**は、症例報告としては不要な冗長表現。研究の意義・仮説を述べる一文で締め、予告は削る。
- 画像所見等について「これは正式な読影ではなく著者らの印象である」のような、**観察者の権威・資格を根拠にした断り書き**は科学的な論法として不適切(誰が見たかではなく、何が見えるかが問題)。正式なレポートが存在しないという**事実**はLimitationsに一度だけ記載すれば足り、本文中の所見の記述自体は「Aが認められた」と事実として簡潔に書く。同じ断り書きを複数箇所に重ねて書かない。

## Scientific writingとしての文章洗練

内容が正確でも、文章そのものがScientific writingとして練れていないと査読で指摘される。個々の指摘に対症療法的に直すだけでなく、大きな改稿が一段落した段階で原稿全文を通しで読み直し、以下の観点でセルフレビューする。

- **代名詞の指示先を曖昧にしない**: "X; it failed to improve; it was attributed to Y" のように、セミコロンで文をつなぎながら "it" を連鎖させると、後続の"it"が何を指すか読者が遡って探す必要が生じる。特に主語が変わりうる文脈(処置の対象・症状・検査値等が入れ替わりで登場する記述)では、代名詞を使わず主語を明示的に反復する方が明快。
- **1パラグラフ1論点**: LimitationsやDiscussionは書き足すたびに新しい論点(測定法の限界、基準点補正の説明、画像データの限界、統計的頑健性など)が同じ段落に積み増されがちで、気づくと7つも8つも異なる論点が1段落に詰め込まれた「壁のような段落」になる。論点が変わる箇所で改段する。特に、既存の限界の記述に**新しい種類の限界(測定機器の話→基準点の話、等)を追記するときは、新しい段落を起こす**ことを既定動作にする。
- **AI文章特有の癖を系統的に洗い出す**: 個別の指摘への対症療法だけでなく、原稿全文を確認する回では以下を横断的に検索する。
  - 機械的な列挙構造("(1)...(2)...(3)..."を地の文に埋め込む形): 実際の掲載論文は地の文で書くことが多いため、番号を外して接続語でつなぐ文章に書き直す。
  - 弱い婉曲表現("it raises awareness that X should..."、"認識を高め"等の遠回しな言い方): 「Xすべきである」という直接的な主張に言い換える。
  - 同じ免責・言い訳表現の重複("正式なレポートがない"、"外来診療という制約から実施しなかった"等): 一度述べれば足りる事実は1箇所に集約し、理由の弁明ではなく事実の記述に留める。
- **相互参照は見出し変更のたびに壊れる**: セクション見出しを追加・削除・統合した後は、"see Diagnostic Assessment, above" のような本文中の参照先が実在するかを必ずgrepで確認する。見出しをフラット化(地の文への統合等)した場合は特に見落としやすい。
- **この一巡は「これまでの指摘を思い出す」のではなく、原稿を新規に読み直して行う**: 過去に指摘されたのと同じパターンの問題が、その後の加筆で別の場所に新たに生まれていることが多い(例: 基準点補正の説明を追記した際に、Limitations段落がさらに長大化する等)。
