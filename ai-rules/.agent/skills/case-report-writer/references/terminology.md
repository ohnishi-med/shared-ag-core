# 用語の技術的正確性

読むタイミング: 医学専門用語・略語を使う時。

- 医学専門用語で数値定義を伴うもの(例: large-volume paracentesis = 1回≥5L)は、**本文で使う前に定義を確認する**。実測値がその定義域外の場合は、より正確な代替語(頻回の穿刺、等)に置き換える。記憶だけに頼らず、不確かな場合はWeb検索で一次資料(ガイドライン等)を確認する。
- 略語は初出時に定義し、Abbreviations一覧および各Tableの脚注用語集の**両方**に反映されているか確認する。
- 科学論文らしくない物語的・感情的・曖昧な表現(「象徴的な」「pivotal episode」を安易に多用する等)は、査読者から指摘されうる。中立的で検証可能な表現に置き換える。
- タイトル・Abstractでは、具体的な疾患名を挙げる("non-surgical conditions"のような曖昧なカテゴリ語だけで済ませない)。
- 日本語訳を作成する場合、英語の文構造をそのまま逐語訳すると翻訳調になる。日本語として自然な語順・接続詞に組み替える(特にKnown→Unknownの順序や、修飾節の入れ子は日本語の方が語順の自由度が低く重く感じられやすい)。
- **観察研究(多数例の統計的関連を扱う)特有の用語を、n=1の症例報告のLimitationsに転用しない。** 「交絡(confounding)」はある曝露とアウトカムの関連を集団内で推定する際に第三の変数が歪みを生む現象を指す統計的概念であり、単一症例には厳密には適用できない。「他の要因を除外しきれない」という趣旨は、"contributing factors that were not systematically assessed"(体系的には評価していない要因の関与)のように、n=1でも成立する表現に置き換える。
