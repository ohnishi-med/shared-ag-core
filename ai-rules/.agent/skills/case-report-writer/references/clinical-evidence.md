# 診断根拠・臨床判断の明示性(印象ではなくデータで語る)

読むタイミング: 診断根拠・重症度分類・画像所見等の臨床判断を記述する時。

査読者・読者が「誰が見ても同じ判断に至れる」ように、臨床判断の根拠は必ず明示的な基準と結び付けて記載する。

- **重症度分類は内訳を示す**: Child-Pugh分類等の複合スコアは、結論(例: Class C)だけでなく、**採点項目ごとの点数内訳**(ビリルビン○点、アルブミン○点、INR○点、腹水○点、脳症○点、など)を本文に明記し、読者が検算できるようにする。
- **検査値の異常≠臨床診断**であることに注意する。ある所見(例: 肝性脳症)を検査値(例: アンモニア高値)だけを根拠に記載していないか確認する。臨床診断には本来の診断基準(意識レベル、羽ばたき振戦の有無等)があるはずで、それに基づいているかをカルテ・ユーザーに確認してから記載する。
- **重症度の閾値は本文中にその場で明記する**: 睡眠時無呼吸症候群の重症度(AASM基準)等、使用した分類基準の数値閾値を、初出箇所で簡潔に併記する。
- **基準値は「高値」「異常」と書く箇所で都度示す**: 表を見に行かないと基準範囲が分からない、という状態を避ける。
- **画像所見(CT/エコー等)の記載は読影の専門性の範囲を超えない**: 正式な放射線科・循環器科レポートがない所見を記載する場合、「著者らによる形態学的な印象であり、正式な読影ではない」と明記する。特に、特定の臓器の一部(心腔の種類等)を名指しする識別は専門的な読影相当の判断を要するため、正式なレポートがない場合はより一般的な表現(「心陰影の変形・偏位」等)に留める。ユーザーから「読影の責任は論文に適さない」等の指摘があった場合は、定量化・数値化してもこの原則は変わらないことに注意する(測定値化しても「これは圧排である」という解釈自体は読影相当の判断であるため)。
- **測定法の「直接/間接」と「標準化されているか」は別軸**: 例えば経膀胱的圧測定は広く標準化されているが解剖学的には間接測定であり、腹腔から直接圧を取る簡易水柱法は逆に直接測定だが非標準、ということがありうる。「標準的でない=劣っている・間接的」と短絡しない。限界として書くべきは「較正されたトランスデューサーでない」等の技術的精度の話であり、「間接的だから信頼性が低い」という誤った理由付けをしない。
- **Discussionの機序(Mechanism)は明確な因果連鎖で書く**: 「Aという所見がBを支持する(support)」のような曖昧な言葉で複数の所見を並べるのではなく、「Aという所見(CT/エコーでの圧排)があり、介入(腹水穿刺)によってAが解除され、それがCという結果(血行動態安定化)に寄与した」という明示的な連鎖で記述する。
- **Abstractには因果関係が弱い所見を含めない**: Discussion本文で「非特異的」「独立して診断的ではない」と自ら断っているような所見は、Abstractには載せない。Abstractは最も直接的で論理の通った所見を優先する。
