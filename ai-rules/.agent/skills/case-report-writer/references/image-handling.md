# 画像データ(CT・エコー等)の取り扱い

読むタイミング: CT/エコー等の画像データを扱う時。

- **元の画像ファイルは絶対に上書き・加工しない。** 必ず別名でコピーしたファイルに対してウィンドウイング・トリミング・注釈等を行い、原本は読み取り専用のものとして保管する。
- CT画像はしばしば16-bit グレースケールで保存されており、素朴にPNG変換すると不適切な諧調(ポスタリゼーションのように見える)になることがある。実際のピクセル値のヒストグラムを確認し、適切な窓幅・窓中心(パーセンタイルベースのウィンドウイング等)を設定してから8-bitに変換する。
- SVG形式の注釈済み画像は、環境にInkscapeが入っていればCLI(`inkscape --export-type=png --export-filename=... --export-dpi=...`)でPNG変換できる。
- 患者個人を特定しうる情報(施設名・患者ID・生年月日等の焼き込み文字)が画像内に写り込んでいないか、使用前に必ず確認する。PACSビューアのスクリーンショットは特に注意する。
