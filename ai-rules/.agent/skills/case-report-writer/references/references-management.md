# Reference・書誌情報の管理

読むタイミング: 文献番号を追加・削除する時。

- 文献番号は本文中の初出順に連番を振る。
- 文献を追加・削除した際は、本文中の**全引用箇所**の番号がずれていないか grep 等で機械的に確認する(手作業での再確認は漏れやすい)。
- CARE guidelines文献を含め忘れない。
- **本文中で言及する具体的な数値基準(診断閾値、感度・特異度等)を新たに追加する場合、記憶だけに頼らず、必ずWeb検索等で一次資料(原著論文・ガイドライン)を確認してから引用文献リストに追加する。** 著者名・年・誌名・巻号・ページは複数のソースで相互確認する。不確かな場合は「文献情報を要確認」とユーザーに伝え、断定しない。
