# CARE準拠は「明言」ではなく「実質」で満たす

読むタイミング: Case Presentationの構成を組む時、CARE準拠を確認する時。

Backgroundの末尾に "This case report is written in accordance with the CARE guidelines" と書くだけでは不十分。**Case Presentation内の見出し・内容構成が実際にCARE標準に沿っているか**を照合する。

- CARE標準のCase Presentation構成: **Patient information → Clinical findings → Timeline → Diagnostic assessment → Therapeutic intervention**(→ 独立した Follow-up and Outcomes)。BMJ Case Reports系なら Case presentation → Investigations → Differential diagnosis → Treatment → Outcome and follow-up。
- 圧縮や書き直しの過程で、"Patient background." "Central clinical observation." のような**自己流の見出し**を作ってしまうことがある。読み慣れない見出しは大抵、標準名称からの逸脱のサインなので、都度CARE標準の名称に置き換えられないか確認する。
- 見出し名を標準名に変えるだけでなく、**内容の割り振りも標準構成の意味に合わせて組み替える**。例: 治療への反応の観察と治療のプロトコル自体(何mL排液後に何を開始するか等)は別セクション(Clinical findings / Therapeutic intervention)に分離する。経過中に生じた所見(合併症、随伴症状等)も "Clinical findings" に含めてよい(Diagnosisの前段階に限定しない)。
- 診断の手がかりが治療への反応そのものである症例(ex juvantibus diagnosis)では、時系列上「治療的介入」が「診断的評価」より先に始まることがある。これはCARE構成として問題ない(Timelineの表が正確な時系列を別途担保していれば、本文の節構成は主題別でよい)。
- **CARE標準の小見出し(Patient information/Clinical findings等)は理論上の推奨であり、投稿先ジャーナルの実際の掲載慣行と食い違うことがある。** 投稿規定ページの記述を鵜呑みにせず、可能なら同一ジャーナルの掲載済みCase Reportを実際に10本前後確認し、見出し構成・段落分けの実態を検証する。理論(CAREガイドライン文書やジャーナルの投稿規定ページ)と実践(実際の掲載論文)が食い違う場合は、査読者が見慣れている実践側の体裁を優先する。例: BMC系ジャーナルでもCase Presentationが完全な地の文(小見出しなし)で書かれているのが実際の主流であることがある。1〜3本の確認では偶然の偏りがありうるため、判断が変わりうる規模(見出し構成の大幅な変更等)ではより多くの実例で裏取りする。
