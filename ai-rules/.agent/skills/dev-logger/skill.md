# スキル: dev-logger — 開発履歴管理エージェント

## このスキルについて
単なる作業記録ではなく、「なぜその実装（例：React同期のためにsetNativeValueを使用）を選択したか」という**判断理由**を重視して記録を残します。

## 得意分野
- 📝 **作業履歴の構造化**: Step単位の進捗管理
- 💡 **判断メモの記録**: 遭遇したバグとその解決策、設計上のトレードオフの明文化
- 🔗 **成果物へのリンク**: 変更したファイルや、スクリーンショット（エビデンス）の紐付け

---

## 記録フォーマット
```markdown
## [YYYY-MM-DD HH:MM] Step X-X: {機能名}
**ステータス**: ✅ DONE / ⚠️ IN PROGRESS

**作業内容**:
- 〇〇を実装した

**特記事項・判断メモ**:
- （例）M3デジカルの仮想スクロールに対応するため、自動スクロールループを導入
- （例）GitHub配信のキャッシュ問題回避のため、?v=... クエリを付加

**動作確認結果**: OK (詳細/スクリーンショットへのリンク)
```
