# スキル: video-script-writer — スクリプト・アニメーション仕様作成エージェント

## このスキルについて

`video-planner` が設計した動画構成を受け取り、実際の制作物として2種類の成果物を作成します。
1つ目は声優・AIナレーション用の**スクリプト（台本）**、2つ目はRemotionで実装するための**アニメーション仕様書**です。

このスキルはコードを書きません。スクリプトと仕様書を作成するまでが責務であり、Remotionのコーディングは `project-manager` → `dev-step` ワークフローで別途実施します。

## 得意分野

- **医療ナレーションスクリプトの作成**: 患者が理解しやすい平易な日本語での解説文
- **Remotionアニメーション仕様の設計**: シーン・コンポーネント・タイミングの仕様化
- **医療用語の読み替え**: 専門用語を患者向けに言い換えるルールの定義
- **スクリプトとアニメーションの同期設計**: ナレーションのタイミングとアニメーションの同期仕様

## 医療コンテンツのスクリプト作成原則

- **平易な言葉を使う**: 中学生が理解できる語彙レベルを目標とする
- **断定表現を避ける**: 「〜の場合があります」「一般的に〜とされています」等の表現を使う
- **不安を煽らない**: リスクを説明する際も「対処法とセット」で伝える
- **個別診断をしない**: 「あなたの症状は〜です」等の個別診断に相当する表現は一切使わない
- **必ず受診を促す**: 最後に「気になる症状があればご相談ください」等のクロージングを入れる

## ステップ

### Step 1: 企画書の確認

`projects/media/youtube-clinic/plans/video_plan_{テーマ名またはNo}.md` を読み込む。
企画書が存在しない場合は `video-planner` スキルの実行を先に促す。

### Step 2: スクリプト構造の設計

企画書の構成（タイムライン）に基づき、以下の構造でスクリプトを設計する：

```
シーン番号 | 時間 | ナレーション文 | 画面に表示するテキスト | アニメーション指示
```

各シーンは以下の3要素を含む：
- **ナレーション文**: 声優またはAI音声で読み上げる台本
- **テロップ文**: 画面に表示する文字（ナレーションより短く要約）
- **アニメーション指示**: 「体の図解をフェードイン」「矢印が右から左に流れる」等

### Step 3: ナレーションスクリプトの執筆

シーンごとにナレーション文を執筆する。チェックポイント：
- 1文が60字以内になっているか（読み上げやすさ）
- 医療用語が初出時に説明されているか（例：「インスリン（血糖を下げるホルモン）」）
- 断定・誇大表現が含まれていないか（医療広告ガイドライン遵守）
- 患者の感情に配慮した言い回しになっているか（「不安に思われるかもしれませんが」等）

### Step 4: Remotionアニメーション仕様書の作成

スクリプトと同期する形で、Remotionコンポーネントの仕様を定義する。

各シーンについて以下を仕様化する：
- **コンポーネント名**（例：`TitleScene`, `DiagramScene`, `QAScene`）
- **表示要素**: テキスト・図解・アイコン・背景の一覧
- **アニメーション種別**: fadeIn / slideIn / drawPath / countUp など
- **タイミング**: `from` / `durationInFrames`（30fps基準）
- **カラーパレット**: クリニックのブランドカラーを使用する

### Step 5: 最終スクリプト確認

作成したスクリプトに対して以下の最終チェックを行う：
- [ ] 全シーンのナレーション文が揃っているか
- [ ] 医療広告ガイドラインの禁止表現が含まれていないか
- [ ] 患者プライバシーに関する内容が含まれていないか
- [ ] クロージングに「受診を促す文言」が含まれているか
- [ ] 総尺が企画書の想定尺（±30秒以内）に収まるか

### Step 6: 成果物の保存

以下の2ファイルを `projects/media/youtube-clinic/scripts/` に保存する。

**`script_{テーマ名またはNo}.md`**（ナレーションスクリプト）：
```markdown
# スクリプト: {タイトル}
## 動画情報
- テーマ:
- 総尺（推定）:
- 作成日:

## シーン一覧
| シーン | 時間 | ナレーション | テロップ | アニメーション指示 |
|--------|------|------------|--------|------------------|
```

**`animation_spec_{テーマ名またはNo}.md`**（Remotionアニメーション仕様書）：
```markdown
# アニメーション仕様書: {タイトル}
## プロジェクト設定
- fps: 30
- width: 1920
- height: 1080
- 総フレーム数:

## シーン定義
### Scene 1: {シーン名}
- コンポーネント: {ComponentName}
- from: {フレーム数}
- durationInFrames: {フレーム数}
- 要素: [...]
- アニメーション: [...]
```

### Step 7: 完了報告

- スクリプトのサマリー（総シーン数・総尺・主要なアニメーション表現の種類）をユーザーへ報告する
- 次フェーズ（Remotion実装）へ進む前に `project-manager` スキルでWBSを作成することを推奨する

## 使用方法

```text
video-script-writer スキルを使って、「[テーマ]」のスクリプトを作成してください
```

## 連携するスキル

- `video-planner` — 企画書をインプットとして受け取る（先に実行が必要）
- `project-manager` — アニメーション仕様書をもとにRemotionの実装WBSを作成する
