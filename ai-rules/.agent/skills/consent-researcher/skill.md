# スキル: consent-researcher — 同意書情報収集エージェント

## このスキルについて

指定されたテーマ（疾患や手術、治療内容など）に基づき、同意書・同意文書の作成に必要な要件をガイドラインや信頼できるWebサイトを巡回して収集する専門スキルです。
収集したデータは、後の文書作成で活用しやすいように**JSON形式**で構造化して保存します。

## 得意分野

- 🔍 **医療・法的リサーチ**: 学会ガイドラインやや信頼できる医療機関サイトからの情報収集
- 📚 **同意書要件の抽出**: 治療内容のほか、リスク、合併症、代替治療など、説明義務を果たすための必須項目の抽出
- 💾 **構造化データ化**: 収集した要素をJSONフォーマットで定義し出力する

## 使用方法

このスキルを呼び出す例：

```text
consent-researcherを利用して、「白内障手術の同意書」に必要な情報を収集してください。
```

## 処理フロー

1. **テーマの分析**: 指定された治療や処置における重要な要素（法的説明義務を含む）を推測します。
2. **情報検索**: web検索ツール等を用いて、学術的・法的に必要な情報を集めます。
3. **情報の整理とJSON化**: 以下の形式に従い、結果をJSON形式で出力・保存します。

## JSON出力形式

収集したデータは、以下の構造を持つJSON形式（ファイル名は適宜設定）で保存します。

```json
{
  "theme": "調査テーマ名",
  "target": "対象となる治療・処置名",
  "procedure_details": "治療の具体的な手順や内容",
  "purposes_and_benefits": [
    "治療の目的と期待される効果1",
    "期待される効果2"
  ],
  "risks_and_complications": [
    "合併症1（発生頻度などの補足）",
    "合併症2"
  ],
  "alternatives": [
    "代替となる治療法や、治療を行わなかった場合の見通し"
  ],
  "notes": [
    "特記事項（生活上の制限など）"
  ],
  "references": [
    "参考にしたガイドラインやWebサイトのURL1",
    "URL2"
  ]
}
```

## 連携するスキル・ワークフロー

- `document-writer` — このスキルで収集・保存したJSONデータを読み込み、実際の同意書（Word/Markdownなど）の文章を生成します。
