# ワークフロー: summarize-doc — 文書要約

## 説明

指定されたファイルや文章の内容を要約・整理します。
医療同意書の要点整理、戦略文書のまとめ、長文の簡潔化などに使用します。

## 呼び出し方

```
/summarize-doc
```

または対象ファイルを開いた状態で呼び出す。

---

## Steps

### Step 1: 対象の特定

- 現在開いているファイルがある場合 → そのファイルを対象とする
- 指定がない場合 → ユーザーに対象を確認する

### Step 2: 要約の種類を選択

ユーザーに確認する：

- 📋 **箇条書き要約**（要点を箇条書きでまとめる）
- 📄 **1段落要約**（1〜3文で全体を要約）
- 🗂️ **構造化要約**（見出しごとに要点を整理）
- ❓ **Q&A形式**（よくある質問と回答形式）

### Step 3: 要約を生成

選択された形式で要約を生成する。

**出力例（箇条書き要約）:**

```markdown
## 要約：{ファイル名}

**核心:**
- （最も重要な点）

**要点:**
- （要点1）
- （要点2）
- （要点3）

**次のアクション:**
- （もし明確な次のステップがある場合）
```

### Step 4: 確認・調整

ユーザーのフィードバックに基づき、必要であれば要約を調整する。
