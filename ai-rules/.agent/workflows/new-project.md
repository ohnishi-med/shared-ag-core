# ワークフロー: new-project — 新プロジェクト作成

## 説明

新しいプロジェクトフォルダを作成し、必要な初期ファイル（AGENTS.md等）を配置します。

## 呼び出し方

```
/new-project
```

---

## Steps

### Step 1: プロジェクト情報の収集

ユーザーに以下を確認する：

- **プロジェクト名**（英語のフォルダ名）
- **カテゴリー**: `clinic` / `media` / `tools` / `m3-master` / 新規
- **目的・概要**（日本語で1〜2文）
- **使用技術**（Python / JavaScript / GAS / Node.js / Electron / その他）
- ※「Node.js」や「Electron」を使用する場合は、希望のバージョン（指定がなければデフォルトは Node.js v24.15.0 LTS）を確認する。

### Step 2: フォルダ構造の提案

収集した情報を元に、次の構成を提案する：

```
projects/{カテゴリ}/{プロジェクト名}/
├── AGENTS.md        ← プロジェクト固有ルール
├── README.md        ← プロジェクト説明
└── src/             ← ソースコード（任意）
```

ユーザーが承認したら Step 3 へ進む。

### Step 3: ファイルの作成

承認後、以下を作成する：

1. プロジェクトフォルダ
2. `AGENTS.md`（テンプレートに基づいて内容を生成）
3. `README.md`（プロジェクト説明）
4. **Node.js/Electron を使用する場合（環境定義）**:
   - `environment-manager` スキルに従いプロジェクト直下に `.node-version`（例：`24.15.0`）を作成する。
   - `package.json` を生成する場合は、必ず `engines: { "node": ">=24.15.0" }` のような環境依存情報を付与する。

**AGENTS.md テンプレート:**

```markdown
# AGENTS.md — {プロジェクト名}

## プロジェクト概要
{ユーザーが提供した概要}

## 技術スタック
{使用技術}

## ディレクトリ構成
（作成後に記載）

## 注意事項
（プロジェクト固有の注意点）
```

### Step 4: 完了報告

作成したファイルの一覧と次のステップを日本語で報告する。
