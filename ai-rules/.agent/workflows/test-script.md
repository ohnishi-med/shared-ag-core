# ワークフロー: /test-script (スクリプト自動診断)

このワークフローは、Windows上で動作するスクリプト（PowerShell, BAT, VBS）の健全性を自動で診断します。

## 実行手順

1. **診断スクリプトの生成**:
   - 対象のスクリプトを読み込み、一時的な診断プログラム（文法チェック、アセンブリ確認、環境チェック）を作成します。
2. **一括テスト実行**:
   - `run_command` を使用して、以下の項目をバックグラウンドでテストします。
     - 必須アセンブリ（System.Windows.Forms等）のロード可否
     - PowerShellの実行環境（STAモードの要否チェック）
     - スクリプト全体の文法（シンタックス）の妥当性
     - 外部ファイル（MP3等）のパス到達可能性
3. **結果の報告**:
   - `app-tester` スキルのフォーマットに従い、診断結果（OK/NG）を表示します。
   - 異常がある場合は、具体的なエラー箇所と修正案を提示します。

## 使い方
> `/test-script [対象ファイル名]`
