# ワークフロー: create-consent-doc — 同意文書連携作成

## 説明

指定されたテーマに対して、`consent-researcher` スキルを使用して必要な情報をリサーチ・収集し、その結果（JSONデータ等）を用いて `document-writer` スキルで最終的な同意文書（WordやMarkdown形式等）を作成する一連のプロセスを自動化します。

## 呼び出し方

```text
/create-consent-doc [テーマ名（例：白内障手術）]
```

---

## Steps

### Step 1: 情報収集 (consent-researcher)

1. ユーザーから受け取ったテーマに基づき、`consent-researcher` スキルを実行します。
2. 疾患・治療法について、ガイドラインや関連Webサイトから、法的説明義務を満たす情報（目的・効果、合併症、代替治療など）をリサーチします。
3. 収集した結果をJSON形式で整形し、ユーザーに共有します（あるいは作業ディレクトリに一時保存します）。

### Step 2: リサーチ結果のレビュー

1. 取得した情報（特に合併症やリスクに関する項目）をユーザーに提示し、不足や修正指示がないか確認します。
2. ユーザーの承認（OK）が得られるまで待機し、必要があれば再リサーチ・加筆を行います。

### Step 3: 文書作成 (document-writer)

1. ユーザーの承認を得たリサーチ結果をインプットとして、`document-writer` スキルを実行し、同意書を作成します。
2. その際、`document-writer` の必須要件（法的側面の明確化、合併症等発生時の保険医療での対応・費用負担など）が必ず網羅されるように明記させます。
3. 文書化されたテキストは、指定がない場合 `projects/clinic/` 内の適切なフォルダ等（例: `[テーマ名]_同意書.md`など）に出力・保存します。

### Step 4: 完了報告

出力したファイルパスをユーザーに提示し、最終的な内容確認をお願いします。
